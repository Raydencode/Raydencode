# NOTE: this project does NOT use the `keyboard` package for push-to-talk.
# Listening is always-on (see main.py) — `keyboard` installs a global
# keyboard hook to detect key state system-wide, which is the same
# technique real keyloggers use, and some antivirus/endpoint security
# software will flag and block it. Always-on listening + a dashboard mute
# button avoids that entirely.
